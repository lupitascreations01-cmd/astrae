# Duual — App de Compatibilidad Astrológica

Duual es una PWA bilingüe (ES/EN) de compatibilidad astrológica: carta natal real, sinastría entre dos personas y análisis por planeta — no horóscopos genéricos de signo solar.

- 📱 App Android: [Play Store](https://play.google.com/store/apps/details?id=com.duual.app)
- 🌐 Pruébala gratis en la web: [duual-web.vercel.app](https://duual-web.vercel.app)

## Qué hace

- Carta natal (Sol, Luna, Venus, Marte, Mercurio) para dos personas
- Score de compatibilidad con desglose por áreas
- Aspectos planetarios y corrección manual de signos
- Análisis premium con IA (elementos, Venus/Marte profundo, Quirón, Nodo Norte)
- Tarjeta de compatibilidad descargable para Instagram/TikTok

## Stack

HTML/CSS/JS puro, sin frameworks. [Astronomy Engine](https://github.com/cosinekitty/astronomy) para cálculos planetarios reales (con fallback a fórmulas Meeus geocéntricas). PayPal para pagos premium. Desplegado en Vercel.
